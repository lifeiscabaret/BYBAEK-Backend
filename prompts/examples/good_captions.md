# good_captions.md — BETA v0.1

> 이 파일은 임시(베타) 버전입니다. 마케팅 리서치 기반 패턴(Hook-Value-CTA, 구체적 CTA 원칙)을 참고해 새로 작성한 **원본 예시**이며, 실제 계정에서 복사한 문구가 아닙니다.
> `BYBAEK_캡션_리서치_템플릿.xlsx`로 수집한 실데이터가 쌓이면 이 파일을 교체/보강할 예정입니다.
> 각 예시는 post_writer 평가기준(예약문의유도 40% · 페이드키워드 25% · CTA강도 15% · 브랜드톤 10% · 타겟공감 10%)에 맞춰 작성했습니다.

---

## 톤 카테고리별 사용법

프롬프트 조립 시, 샵의 `brand_tone` 배열과 아래 카테고리 태그가 겹치는 예시 1~2개만 선택해서 주입할 것 (전체를 다 넣지 말 것 — 톤 획일화 방지).

| 카테고리 태그 | brand_tone 예시 매칭 |
|---|---|
| `narrative` (비포애프터 서사형) | "감성/무드", "스토리텔링" |
| `expertise` (전문성 강조형) | "전문적/신뢰", "디테일 강조" |
| `humor` (유머러스형) | "10~20대", "가볍고 재밌게" |
| `community` (친근·커뮤니티형) | "단골 중심", "따뜻한 톤" |
| `tips` (정보·꿀팁형) | "정보성", "실용적" |

## 1. narrative — 비포애프터 서사형

### 예시 1-1
```
이번 손님, 취업 면접 앞두고 오셨어요. "단정한데 너무 튀지 않게"가 미션이었습니다.
사이드는 바짝 올리고 탑은 살려서 자연스러운 페이드컷으로 마무리했어요.
거울 보시더니 표정이 확 풀리시더라고요 😌 다음 주 면접, 자신 있게 들어가실 거예요.

페이드컷 원하시는 분들 편하게 DM 주세요. 이번 주 평일 오후 자리 여유 있습니다.
```
**왜 좋은가**: 구체적 상황(면접) → 시술 디테일(페이드컷) → 감정 변화 → 구체적 CTA(DM+요일/시간대 명시). 예약문의유도·페이드키워드·CTA강도 모두 충족.

### 예시 1-2
```
3개월 만에 오신 단골님. 처음엔 투블럭도 부담스러워하셨는데, 오늘은 먼저 "더 짧게 가도 될까요?" 물어보시더라고요.
그만큼 믿어주신다는 뜻이라 저도 기분 좋았습니다. 페이드는 스킨까지 바짝, 윗머리는 볼륨감 살려서 마무리했어요.

아직 첫 방문 안 해보신 분들, 프로필 예약 링크 편하게 눌러주세요 — 첫 상담은 항상 꼼꼼하게 해드립니다.
```
**왜 좋은가**: 재방문 고객 서사로 신뢰도 자연스럽게 어필, 신규 고객 대상 CTA로 자연스럽게 전환.

## 2. expertise — 전문성 강조형

### 예시 2-1
```
오늘 이 라인 하나 잡는 데만 다섯 번을 다시 봤습니다. 페이드는 각도 1mm 차이로 인상이 완전히 달라지거든요.
헤어라인 따라 자연스럽게 떨어지는 그라데이션, 이게 페이드컷에서 제일 신경 쓰는 부분이에요.

디테일까지 신경 쓴 컷 원하시면 프로필 링크로 예약 확인해보세요.
```
**왜 좋은가**: 구체적 기술 디테일(각도, 그라데이션)로 전문성 어필 → 고관여 CTA. brand_tone "전문적/신뢰"와 강하게 매칭.

### 예시 2-2
```
많이들 헷갈려 하시는데, 스킨페이드랑 로우페이드는 얼굴형에 따라 어울리는 게 완전히 달라요.
각진 얼굴이면 스킨페이드가 라인을 살려주고, 갸름한 얼굴이면 로우페이드가 밸런스를 잡아줍니다.

본인 얼굴형에 맞는 스타일 궁금하시면 예약하실 때 편하게 물어보세요, 상담부터 꼼꼼히 도와드립니다.
```
**왜 좋은가**: 정보 제공 + 개인화 상담 CTA로 예약 문턱을 낮춤.

## 3. humor — 유머러스형

### 예시 3-1
```
월요일 아침엔 커피보다 페이드가 필요합니다 ☕✂️ 정신 번쩍 들게 스킨까지 바짝 밀어드렸어요.

한 주의 시작, 머리부터 깔끔하게 가고 싶으신 분들 — 이번 주 자리 몇 개 남았어요. DM 주세요.
```
**왜 좋은가**: 짧고 임팩트 있는 훅(첫 줄), 가벼운 톤이지만 CTA는 명확. 10~20대 타겟에 적합.

### 예시 3-2
```
손님이 "알아서 해주세요" 하시면 사실 제일 떨립니다 😂 근데 이번엔 믿어주신 보람이 있었네요.
크롭컷으로 과감하게 갔는데 반응이 폭발적이었어요 (제 반응 포함).

"알아서 해주세요" 스타일 믿고 맡기실 분들 환영입니다, 프로필 링크로 예약 가능해요.
```
**왜 좋은가**: 관계 코미디로 공감 유발, 특정 고객 페르소나(맡기는 스타일)를 타겟팅하는 CTA.

## 4. community — 친근·커뮤니티형

### 예시 4-1
```
이 자리에서 벌써 3년째 뵙는 단골님들이 늘고 있어요. 오늘도 "여기 아니면 다른 데 못 가겠다"는 말씀해주셔서 정말 감사했습니다.
저희는 그냥 머리만 자르는 게 아니라, 편하게 앉아서 한 주 얘기하는 시간까지 만들고 싶어요.

새로 오시는 분들도 편하게 오세요, 첫 방문이라고 어색해하실 필요 전혀 없습니다 — 예약은 DM으로!
```
**왜 좋은가**: 소속감/신뢰 서사로 신규 고객의 진입 장벽을 낮춤.

### 예시 4-2
```
오늘 100번째 페이드컷 손님이었습니다 🎉 처음 문 열었을 때만 해도 상상 못 했던 숫자예요.
여기까지 올 수 있었던 건 다 믿고 찾아와주신 분들 덕분입니다.

감사한 마음으로 이번 주는 신규 예약 조금 더 여유 있게 받고 있어요. 편하게 DM 주세요.
```
**왜 좋은가**: 마일스톤 서사 + 감사 톤 + 자연스러운 예약 유도.

## 5. tips — 정보·꿀팁형

### 예시 5-1
```
페이드컷 하고 나서 2주 지나면 목선이랑 옆머리부터 지저분해 보이기 시작해요.
그때가 바로 "라인 정리"만 살짝 받으러 오시면 되는 타이밍입니다 — 전체 컷 다시 안 하셔도 돼요.

라인 정리만 필요하신 분들도 편하게 예약 가능합니다, 시간 얼마 안 걸려요.
```
**왜 좋은가**: 실용 정보 제공으로 신뢰 구축, 저관여 서비스(라인정리)로 예약 문턱을 낮춤.

### 예시 5-2
```
많이 물어보시는 질문 하나. "왁스 vs 포마드, 뭐가 나아요?"
짧은 페이드컷엔 매트한 질감의 왁스가 자연스럽고, 볼륨감 살리고 싶으면 포마드가 낫습니다.

스타일링 방법까지 같이 알려드리니, 컷 받으실 때 편하게 물어보세요. 예약은 프로필 링크로!
```
**왜 좋은가**: Q&A 포맷으로 훅 강화, 부가가치(스타일링 팁) 제공 후 CTA.
